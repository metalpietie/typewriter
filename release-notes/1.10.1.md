## Version 1.10.1: fixes from a code review

### Fixed
- **Moving a book to another shelf:** links in the text are fixed (an @ link loses its link, the name stays; a citation becomes plain text marked "needs a source"; comments keep their marks). A move that fails half way takes its copy out again. Old snapshots no longer break after a move. A new or moved book goes after the highest number on the shelf.
- **Bookshelf screen:** search results open in front of the shelf; shortcuts behind the shelf do nothing; Esc in Project settings keeps the shelf; renames and removals in "Manage shelves…" show at once; new covers show; the book you are writing in keeps its chapter and scene; Enter on ↻ makes a new cover; wheel scrolling while dragging moves the drop place; saves are checked before a move or a project switch; a missing project file shows a warning; word counts match the Write screen.
- **Vim keys:** Esc in focus mode; Enter, Backspace, Delete and Tab in Normal mode; Ctrl+B bold in Visual mode; AltGr keys; line breaks in text objects; no @ list in Normal mode; the cursor stays when Vim is switched.
- **Data safety:** a project switch waits for a phone sync, the daily backup and bookshelf jobs; unique project ids; the phone pairing file is written safely; links to deleted scenes and chapters are cleared (Undo brings them back).
- **Docs:** the Using Typewriter guide has no copied half any more; the README restore steps are fixed.

### Notes
- After moving a book, plot holes you had dismissed for its scenes may show again.
- Switching the Vim keys on or off still starts the undo history again.
- The Android app is unchanged and stays at 1.8.0.

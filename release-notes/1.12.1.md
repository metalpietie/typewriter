## Version 1.12.1: the window stays maximized

### Fixed
- **The window remembers if it was maximized.** Close Typewriter while the window is maximized, and it opens maximized again the next time.

### Notes
- The setting is in `window.json`, in the Typewriter settings folder. Delete the file to go back to the normal window.
- The Android app is unchanged and stays at 1.8.0.

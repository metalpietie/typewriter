## Version 1.12.0: a Code font for the editor

### New
- **Code font.** A new font for the text editor: JetBrains Mono Nerd Font. All its letters have the same width, so the cursor and Vim keys line up well. Pick it under **Look** > **Font** > **Code**. It comes with the app, so you do not have to install it.

### Fixed
- After an update on Windows, the old program file (`typewriter.exe.old.…`) is now deleted the next time the app starts.

### Notes
- The font is JetBrains Mono (no ligatures) from Nerd Fonts, under the SIL Open Font License. The license is in `frontend/public/fonts/JetBrainsMono-OFL.txt`.
- The app file is about 4 MB bigger because of the font.
- The Android app is unchanged and stays at 1.8.0.
